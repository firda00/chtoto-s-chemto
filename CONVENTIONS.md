# Соглашения монорепо

Каждый проект живёт в своей папке и полностью автономен (свой `pyproject.toml`, свой `.venv` через `uv`).

## Стек
- Python 3.12, менеджер пакетов `uv` (`uv sync`, `uv run pytest`, `uv run <cli>`).
- Код в `src/<package>/`, тесты в `tests/`, точка входа — CLI на `typer` и/или API на FastAPI.
- Pydantic v2 для схем и structured outputs.
- `ruff` для линта (конфиг в pyproject).

## LLM / эмбеддинги
- Любой вызов LLM идёт через модуль `llm.py` проекта с единым интерфейсом `complete(prompt, system=None, json_schema=None) -> str|dict`.
- Провайдер — OpenAI-совместимый endpoint. Переменные окружения:
  - `LLM_BASE_URL` (по умолчанию `https://openrouter.ai/api/v1`; для Ollama — `http://localhost:11434/v1`)
  - `LLM_API_KEY`
  - `LLM_MODEL` (по умолчанию `qwen/qwen3-8b` или аналог)
- `MockLLM` — детерминированная заглушка для тестов. Тесты НИКОГДА не ходят в сеть и не требуют ключей.
- Эмбеддинги: `fastembed` (ONNX, без torch) как основной локальный вариант + `HashingEmbedder` (numpy) для тестов. Torch в зависимости не добавлять.

## Данные и внешние сервисы
- Внешние сервисы (Postgres+pgvector, Ollama, Stockfish) — опциональны. Есть docker-compose или инструкция в README, а также in-memory / fake fallback, чтобы всё работало «из коробки».
- Демо-данные лежат в `data/` проекта (маленькие, синтетические, сгенерированы скриптом в `scripts/`).
